# 专注金币（Android 原型）

通过“离开屏幕赚金币、受限应用按预计时间预付金币”增加漫无目的刷手机的阻力。日界线为每天 07:00。

## 已实现

- 非夜间息屏每分钟赚 1 金币
- 每次打开应用都填写目的和预计使用时间
- 每天 07:00 发放 30 启动金币
- 不受限应用直接打开，不提问也不投入金币；受限应用按自行输入的分钟数预付，日间每分钟 3 金币、23:00–07:00 每分钟 6 金币
- 预计时间到后可选择锁屏、回到主屏幕或重新登记并继续使用
- 提前离开应用不退还已经投入的金币
- 每天 07:00 结算剩余金币为虚拟物品，随后余额清零
- 可紧急借 15 金币，次日扣除 30 金币
- 电话、短信、地图、天气、健康等固定免费名单不可更改
- 短视频、小红书、游戏、直播、视频、社区、网文、购物等固定受限名单不可更改
- 固定名单之外的应用可自行设为免费或受限
- 屏幕顶部金币悬浮标记和常驻通知实时显示现有金币
- 使用无障碍应用监听提高划掉任务后和解锁后的识别可靠性
- 小米手机需另外开启后台自启动、设置电池无限制，并在最近任务中锁定本应用
- 首页展示今日屏幕时间、离屏时间、金币收支与历史虚拟奖励
- 本地 JSON 数据导入、导出
- 开机启动的前台计时服务；设备管理权限用于强制锁屏

## 构建

用 Android Studio（JDK 17）打开目录并运行 `app`。最低 Android 8.0，目标 Android 14。

首次启动后允许通知，并按首页“保护状态”的提示开启专注金币应用监听、屏幕使用情况、显示在其他应用上层、设备管理和不受电池优化限制。应用监听负责可靠识别前台应用；屏幕使用情况作为备用；其余权限分别用于登记页和金币悬浮标记、用户主动选择的锁屏及后台常驻。

Android 保留用户停止或强制停止应用的系统控制权，普通应用不能成为绝对不可关闭的进程。小米后台自启动、电池无限制和最近任务加锁可以避免常见的后台清理，但不能绕过系统“强制停止”或用户关闭无障碍权限。
